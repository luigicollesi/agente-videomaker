# Agente Videomaker

Run `videomaker` to view the bundled manual. Read the `edit` skill before editing `film.html`, and use `videomaker skill <name>` for other workflows. Use `videomaker open`, `look`, `render`, `canvas`, and `text3d` as needed.

Use the CLI provided by the installed Agente Videomaker desktop application or the project's local package. Do not invoke `npx openfilm@latest`: that resolves to the upstream product rather than this fork. The former `openfilm` executable is retained only for backward compatibility.
