# Videomaker compatibility

This legacy skill name is retained for existing agent configurations. Use the bundled `videomaker` CLI and follow its manual and `edit` skill. Do not run `npx openfilm@latest`: that invokes upstream OpenFilm instead of Agente Videomaker.
